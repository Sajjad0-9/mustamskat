# حزمة تطبيق مستمسكات للأندرويد (Mustamskat Android Mobile)

- مصممة خصيصاً لمقاس شاشات الهواتف الذكية بالخلفية `#F0F4EB` والنص `#BDA383`.
- **طريقة التشغيل الفوري على الهاتف بدون بناء**: انقل مجلد `www/` (أو ملف `www/index.html`) إلى هاتفك الأندرويد وافتحه في متصفح Chrome ثم اختر **"إضافة إلى الشاشة الرئيسية (Install App)"** ليعمل بملء الشاشة كتطبيق أندرويد مستقل تماماً بدون إنترنت.
- **طريقة استخراج ملف `.apk`**: عبر Capacitor/Android Studio بالضغط على `بناء_تطبيق_APK.bat` (يولد الملف في `android/app/build/outputs/apk/debug/app-debug.apk`).
